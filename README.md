\# 🎙️ AI Voice Task Manager



An intelligent productivity mobile application that turns unstructured voice notes (including regional dialects like Egyptian Arabic) into structured, actionable daily tasks using AI and Natural Language Processing (NLP).

\## ✨ Key Features



\* 🗣️ \*\*Smart Speech Parsing:\*\* Recognizes natural spoken language (Egyptian Arabic \& Multilingual) and converts it into structured task data.

\* 🤖 \*\*AI-Driven Data Extraction:\*\* Automatically identifies and extracts the task details, date, time, and target completion deadline from a single audio clip.

\* 📌 \*\*Interactive Dashboard:\*\* Dynamic cards on the home screen sorted by time and priority.

\* ✍️ \*\*Manual Fallback:\*\* Quick-add feature to manually write and edit tasks.

\* 🔔 \*\*Deadline Alerts:\*\* Scheduled notifications before tasks reach their target time.



\---



\## 🛠️ Tech Stack



\* \*\*Frontend:\*\* Flutter (Dart)

\* \*\*Speech Processing:\*\* Speech-To-Text / Whisper API

\* \*\*AI/NLP Parsing:\*\* Gemini / OpenAI API (Structured JSON Output parsing)

\* \*\*Local Storage:\*\* Hive / SQLite

\* \*\*State Management:\*\* Riverpod / Bloc
